# 📚 BookShop

A responsive, animated front-end bookshop website built with HTML, CSS, and JavaScript — showcasing manga and anime titles with a clean, modern dark-themed UI.

---

## 📖 Overview

**BookShop** is a front-end e-commerce style website that displays a curated catalog of manga titles such as *Solo Leveling*, *One Piece*, *Hunter x Hunter*, *Tokyo Ghoul*, *Berserk*, and *Shangri-La Frontier*. Each title is presented as a card with a cover image, a short synopsis, and a "Pay" button.

This is an upgraded version of an earlier project I built. The original was one of my first proper HTML websites, created during my first year of university. Since then, I've gone back and improved it with a responsive layout, a mobile-friendly hamburger menu, a dedicated pay page, and smooth animations throughout the site.

> This project is primarily a front-end learning exercise and portfolio piece — it does not process real payments.

---

## ✨ Features

- 🍔 **Hamburger Menu** — Collapsible navigation menu for smaller screens, keeping the layout clean and uncluttered on mobile.
- 💳 **Pay Page** — A dedicated checkout/payment page for a more complete shopping experience (UI only, no real transactions).
- 🎬 **Animations** — Smooth hover effects, transitions, and subtle motion throughout the site to make browsing feel more dynamic.
- 📱 **Responsive Design** — Fully adapts to phones, tablets, and desktops using flexible layouts and media queries.
- 🃏 **Card-Based Catalog** — Each book/manga is displayed in its own card with cover art, title, and description.
- 🌙 **Dark Theme** — A sleek, dark color scheme designed to be easy on the eyes and put the cover art front and center.
- 🧭 **Simple Navigation Bar** — Quick access to Home, About Us, and Contact Us sections.

---

## 🛠️ Built With

- **HTML5** — Semantic structure and markup
- **CSS3** — Styling, responsive layout (Flexbox/Grid), and animations
- **JavaScript** — Hamburger menu toggle and interactive behavior

## 🚀 Getting Started

### Prerequisites

You don't need anything fancy to run this — just a web browser. Optionally, a code editor like [VS Code](https://code.visualstudio.com/) if you want to look at or modify the code.

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/your-username/BookShop.git
   ```

2. **Navigate into the project folder**

   ```bash
   cd BookShop
   ```

3. **Open it in your browser**

   Simply open `index.html` in your browser, or use a tool like the [Live Server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code for live reloading while you make changes.

   ```bash
   # Optional: if you have Live Server installed
   code .
   ```

## 📱 Responsiveness

The layout has been built to scale cleanly across screen sizes:

- **Desktop** — Full multi-column grid layout for browsing books.
- **Tablet** — Adjusted spacing and column counts for mid-sized screens.
- **Mobile** — Single-column layout with the hamburger menu replacing the full navigation bar to save space.
